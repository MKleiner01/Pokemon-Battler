# Pokedex

A menu based Pokedex made in java
The program allows the user to Create, Read, Update, Delete pokemon
as well as save / load from file

1. Make sure you have Java 21
2. Run Pokedex
3. Follow the menu options

# Usage example
When the program starts the user is shown a menu:

1. Show all Pokemon
2. Add Pokemon
3. Edit Pokemon
4. Delete Pokemon
5. Save to file
6. Load from file
7. Reset to Seed data
8. Quit

Enter the number of the action you want
