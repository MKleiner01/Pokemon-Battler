# Pokemon Battler

A menu based Program made in java
The program allows the user to Create, Read, Update, Delete pokemon
that you can use to fight in a turn based battle system.


1. Make sure you have Java 21
2. Run Pokedex
3. Follow the menu options

# Battke system
Affter choosing Start Battle you are allowed to choose a Pokemon from pokedex 
then use it in a fight against the computer.
The computer is assigned a random pokemon out of the pokedex selection
The order of who attacks first is the pokemon with the highest speed stat

# Usage example
When the program starts the user is shown a menu:

-- MENU --
1. Show all Pokemon
2. Add Pokemon
3. Edit Pokemon
4. Delete Pokemon
5. Save to file
6. Load from File
7. Reset to Seed data
8. Start Battle
9. View Battle History
10. Quit
Choose one: 

Enter the number of the action you want
